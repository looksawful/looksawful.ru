Awful Audit

Small audit tool for static front-end projects.

  • GitHub
  • Builds plain text reports for code review, cleanup and AI-assisted analysis
  • Scans source code, Git state, file inventory, assets, imports and class mentions
  • Includes PowerShell and Python versions
  • Supports all, full, assets, css, html, js, cssdist and dist modes

Install

  • Download ZIP
pwsh -NoProfile -ExecutionPolicy Bypass -File .\powershell\install.ps1

cd python
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e .

Usage

Run from any project folder.

au
au all
au full
au assets
au css
au html
au js
au cssdist
au dist

awful-audit all --root path/to/project
awful-audit all --output audit.txt
awful-audit all --no-clipboard
