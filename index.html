              Awful Cases

              Windows tray utility for changing the case and typography of selected text.

              Awful Cases works through global hotkeys. Select text in any editable field, press a shortcut, and the app replaces the selection with the transformed version.

              usage

              start a timer with a duration, a fractional duration, a preset or silent mode.

              usage examples 
              # start a 10 minute timer
python -m src.main 10

# start a 1.5 minute timer
python -m src.main 1.5

# start the small preset
python -m src.main -s

# start silently
python -m src.main 25 --mute
