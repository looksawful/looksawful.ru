# Handoff

Create a compact continuation document without duplicating artifacts that already exist.

Include:
- current goal and explicit non-goals;
- branch/ref and the last verified repository state;
- changed files and why;
- canonical docs/issue/PR/spec links or paths;
- decisions already made;
- unresolved risks/questions;
- exact checks run and their results;
- tests created/moved/deleted when relevant;
- suggested repository-local skills for the next task.

Reference existing commits, diffs, docs and issues instead of pasting them. Redact secrets and unnecessary personal information. Do not claim a PR/check/deployment state from memory.
