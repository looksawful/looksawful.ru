# Looksawful Visual Production

Use this skill for visual assets and art-direction work. It complements, rather than replaces, the Media Catalog, responsive-media pipeline, design system, and authored copy rules.

## Workflow

1. Identify the real source asset, intended placement, target sizes/aspect ratios, readability constraints, and whether exact content must be preserved.
2. Separate exploration assets from production assets. Generated concepts do not become production media by proximity.
3. When adapting an existing source, preserve required identity, logos, product shape, typography, copy, chart values and recognizable subject features unless the task explicitly authorizes a change.
4. Generate or edit at source quality appropriate to the placement, then route final production media through the repository's registered asset / Media Catalog / responsive derivative workflow.
5. Validate dimensions, format, transparency where relevant, crop/focal behavior, mobile composition, file size and browser delivery.

## Guardrails

- Do not invent factual claims, prices, awards, client names, metrics, captions or readable brand copy inside generated art.
- Do not overwrite retained source masters while optimizing delivery assets.
- Do not hand-edit generated media manifests or responsive variants.
- Do not replace a supplied visual reference with a merely similar generated asset when fidelity is required.
- Keep experimental prompt/reference material out of production paths unless it has an explicit repository role.
- Prefer deterministic export steps for final assets and record source/provenance when licensing or reuse matters.

## Review

Evaluate hierarchy, subject fidelity, crop, typography/readability, contrast, artifacting, consistency with the surrounding case, responsive behavior and whether the asset communicates the intended fact or story.

## Refactor boundary

A visual refresh must not silently rewrite product UX, content claims, CSS architecture or media ownership. Those changes require their owning workflow and tests.
