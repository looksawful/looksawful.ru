# portfolio clean architecture

Запускать из корня проекта. Скрипт переносит результат stage 01/02/03 в реальные HTML/CSS/JS, удаляет временные stage-модули, создаёт постоянные модули TOC/галерей/текстового потока и делает локальный бэкап изменяемых файлов в `tools/portfolio-clean-backups/<timestamp>`.

Защищённые зоны: hero, resume, site-header, proximity, playlist filter, policy book, artifact reader, canvas/gsap-визуалы.
