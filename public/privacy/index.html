Приватность и аналитика

Обновлено: 5 сентября 2026

На looksawful.ru используются два инструмента статистики с разными задачами: Cloudflare Web Analytics для агрегированной статистики и производительности страниц и Яндекс Метрика для поведенческой аналитики. Для Яндекс Метрики действует региональный режим: в сессии, определённой как российская, счётчик может запускаться автоматически; для остальных и неопределённых сессий требуется явное согласие.

Cloudflare Web Analytics

Cloudflare Web Analytics используется для оценки просмотров страниц, производительности и Core Web Vitals. По документации Cloudflare этот сервис работает без cookie, собирает минимальный объём данных для статистики и не отслеживает отдельных посетителей между сайтами.

Яндекс Метрика

Счётчик Яндекс Метрики № 112065623 может включаться без отдельной плашки, если текущая браузерная сессия определена как российская и посетитель ранее явно не запретил аналитику. Для сессий вне России и для сессий, регион которых определить не удалось, Метрика загружается только после выбора «Принять». Явно сохранённый запрет имеет приоритет над региональным режимом.

После запуска Метрика может обрабатывать технические сведения о посещении и устройстве, источнике перехода, просмотренных страницах и действиях на сайте. Включены стандартные функции click map, link tracking, accurate bounce и Webvisor. Обработка IP-адреса и другие параметры зависят от настроек счётчика и условий сервиса Яндекс Метрика.

Сайт отправляет в Метрику только следующие собственные цели:

  • project_open — переход к проекту;
  • cv_open — открытие резюме;
  • contact_email — переход по email-ссылке;
  • contact_phone — переход по телефонной ссылке;
  • contact_telegram — переход в Telegram;
  • download — запуск скачивания по ссылке с атрибутом download.

В параметры этих целей не передаются введённые пользователем тексты, имя, email, телефон или другие самостоятельно введённые персональные данные.

Согласие и региональный режим

Явный выбор хранится только в браузере этого устройства в localStorage под ключом looksawful:analytics-consent. Значение может быть granted или denied. Определённый регион хранится отдельно только на время текущей браузерной сессии в sessionStorage под ключом looksawful:analytics-region и не считается постоянным согласием. При Global Privacy Control или Do Not Track аналитика не включается независимо от региона и сохранённого разрешения.

Явный выбор можно сбросить здесь. После сброса на следующей странице с аналитикой снова применяется региональное правило: в российской сессии Метрика может запуститься автоматически, а в остальных или неопределённых сессиях сайт снова предложит принять или отклонить её.
