Приватность и аналитика

Обновлено: 5 сентября 2026

На looksawful.ru используются два инструмента статистики с разными задачами: Cloudflare Web Analytics для агрегированной статистики и производительности страниц и Яндекс Метрика для поведенческой аналитики. Яндекс Метрика загружается только после явного согласия посетителя.

Cloudflare Web Analytics

Cloudflare Web Analytics используется для оценки просмотров страниц, производительности и Core Web Vitals. По документации Cloudflare этот сервис работает без cookie, собирает минимальный объём данных для статистики и не отслеживает отдельных посетителей между сайтами.

Яндекс Метрика

Счётчик Яндекс Метрики № 112065623 включается только после выбора «Разрешить». До этого скрипт Метрики не загружается.

После согласия Метрика может обрабатывать технические сведения о посещении и устройстве, источнике перехода, просмотренных страницах и действиях на сайте. Включены стандартные функции click map, link tracking, accurate bounce и Webvisor. Обработка IP-адреса и другие параметры зависят от настроек счётчика и условий сервиса Яндекс Метрика.

Сайт отправляет в Метрику только следующие собственные цели:

  • project_open — переход к проекту;
  • cv_open — открытие резюме;
  • contact_email — переход по email-ссылке;
  • contact_phone — переход по телефонной ссылке;
  • contact_telegram — переход в Telegram;
  • download — запуск скачивания по ссылке с атрибутом download.

В параметры этих целей не передаются введённые пользователем тексты, имя, email, телефон или другие самостоятельно введённые персональные данные.

Согласие

Выбор хранится только в браузере этого устройства в localStorage под ключом looksawful:analytics-consent. Значение может быть granted или denied. При Global Privacy Control или Do Not Track аналитика, требующая согласия, не включается.

Выбор можно сбросить здесь. После сброса сайт снова спросит разрешение при следующем посещении страницы с аналитикой.
