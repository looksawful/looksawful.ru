# jestei promo diagonal

Папка для кадров диагональной canvas-анимации блока «промо-организмы».

Что делать:
- добавляй или заменяй здесь изображения и видео;
- поддерживаются webp, png, jpg, jpeg, avif, gif, mp4, webm;
- порядок вывода идёт по имени файла, лучше использовать 01, 02, 03 и так далее.
