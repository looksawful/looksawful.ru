# Technical references and acknowledgements

This file records public technical learning/reference material that informed the project's development. It is provenance context, not advertising and not a license statement.

A link here does **not** mean that the repository copies the linked project's code, that the source endorses this portfolio, or that the linked source owns any part of this repository. Any copied or substantially adapted code remains subject to its own license and should be identified more specifically where required.

Commercial/private course material is intentionally omitted and is not reproduced here.

## Public learning references

### Discover three.js

Free online book covering Three.js, WebGL concepts, scene structure, animation, materials, cameras, loading and application architecture.

https://discoverthreejs.com/book/

### Three.js Fundamentals

Public tutorial series covering Three.js fundamentals and practical WebGL-backed 3D application patterns.

https://threejs.org/manual/en/fundamentals.html

### MDN Learn Web Development

Public learning/reference material for HTML, CSS, JavaScript, browser APIs, responsive layout, accessibility and web-platform fundamentals.

https://developer.mozilla.org/en-US/docs/Learn_web_development

## What is intentionally not listed

- paid/commercial course material merely because it was part of the author's education;
- generic learning platforms where no specific public reference can be stated confidently;
- private course code, exercises or text;
- references whose connection to the actual repository cannot be established.

This conservative rule is deliberate: an acknowledgement should improve provenance, not invent it.
