# Triage labels

The repository uses the canonical Matt triage state vocabulary without aliases.

| Canonical role | GitHub label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Category labels used by triage are `bug` and `enhancement`.

A triaged issue should carry exactly one category role and one state role. These labels describe workflow state; they do not grant permission to merge, deploy, publish, bypass review, or weaken repository guards.
