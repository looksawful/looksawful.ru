# Jestei Pool — integration package

Это не самостоятельная страница и не замена глобальной системы сайта. Пакет содержит только содержимое и локальные правила сцены Jestei Pool, которые были согласованы в прототипе.

## Что внутри

- `src/content/jestei-pool-content.fragment.html` — готовый `.cv-item__content` для существующей сцены Jestei Pool.
- `src/content/jestei-pool-scene.css` — только локальная геометрия и адаптивность Jestei Pool.
- `src/content/jestei-pool-scene.js` — только два поведения, которых нет как готового статичного компонента сцены:
  1. ended-driven последовательность из трёх видео Moves Awful;
  2. lightbox для статичных изображений группы 02 (бывшая группа 05–21).
- `notes/INTEGRATION.md` — точная последовательность подключения.
- `notes/QA.md` — проверка после интеграции.
- `notes/DEPENDENCIES.md` — существующие компоненты сайта, которые пакет переиспользует и не копирует.

## Что намеренно НЕ входит в пакет

Пакет не содержит копий глобальных токенов, Rubik, цветовых тем аккордеона, `patterns.css`, `cv-accordion.css`, `accordion-presentation.css`, MediaItem, MediaGallery, MediaMarquee, BeforeAfter, PlaylistFilterWorkflow или Jestei Theme Organism.

Их нужно оставить такими, какие они уже есть в `prod`.

## Подписи

Возвращена старая логика: подписи находятся под фотографиями и видео как обычные `figcaption[data-media-caption]`.

Никаких hover-подписей и мобильных раскрывающихся подписей в этом пакете нет.

Исключения не создаются: даже группа с движущейся лентой использует обычную подпись под своим кадром. Hover остаётся только визуальным откликом изображения/лайтбокса там, где он нужен, а не способом прочитать подпись.

## Mobile-first

Базовые правила CSS — мобильные. Desktop появляется только через `@media (width >= ...)`.

На мобильном:
- группа 02 — двухрядная горизонтальная лента бренд-системы;
- группа 04 — однорядная горизонтальная лента экранов с нативным scroll-snap;
- группа 07 — существующий MediaMarquee, без нового рантайма;
- группа 14 — большой вводный кадр, двухрядная горизонтальная коллекция квадратных обложек и большой завершающий кадр;
- фильтр, before/after, видео и остальные смысловые feature-блоки остаются крупными и читаемыми.

На desktop:
- группа 02 возвращается в равномерную сетку 2×3;
- группа 04 возвращается в 2×2;
- группа 14 возвращается в 3×3 для квадратной части;
- компактные размеры Camelot и Moves Awful сохранены.

## Цвет и типографика

Файл не задаёт новую цветовую тему и не импортирует шрифт.

Все текстовые цвета наследуются от текущих `--item-*`, а подписи используют существующий контракт `accordion-presentation.css`.

Единственные фиксированные цвета в локальном CSS — физические подложки самих бренд-артефактов (чёрная/белая) и белый браузерный mockup, потому что это часть самого медиа-представления, а не тема аккордеона.
