## Phone mockup

Внутри два кадра:
- `sands-01-01`

## Lookbook marquee

Порядок:
`02 → 03 → 04 → 05 → 06 → 07 → 09 → 10 → 11 → 12 → 13`

Все кадры имеют одинаковую визуальную высоту.

Ширина каждого кадра соответствует реальному aspect ratio исходного изображения.

Marquee:
- использует существующий runtime сайта;
- скорость `72`;
- не останавливается при hover;
- не имеет второго параллельного runtime.

## Подписи

### Desktop

В покое:
- подписи не видны;
- изображение читается целиком.

Hover:
- снизу появляется градиент;
- номер — вторичный;
- текст — semibold;
- marquee продолжает двигаться.

Цвета:
- текст `var(--item-text)`;
- градиент построен из `var(--item-body-bg)`;
- произвольного чёрного overlay нет.

### Mobile / touch

У каждого видимого media surface есть `tabindex="0"`.

Тап:
- фокусирует конкретный кадр;
- показывает ту же подпись и тот же тематический градиент.

Тап по другому кадру:
- переносит focus;
- показывает другую подпись.

Тап вне focusable media:
- снимает focus;
- подпись закрывается.

Никакого JS caption-toggle нет.

## Типографика

Шрифт не задаётся внутри S&S.

Используются только глобальные:
- `--font-primary`;
- `--font-weight-regular`;
- `--font-weight-medium`;
- `--font-weight-semibold`.

Роли:
- description — secondary copy;
- `СММ` — приглушённая project-note;
- launch paragraph — editorial lead;
- caption index — regular / secondary;
- caption title — semibold.
